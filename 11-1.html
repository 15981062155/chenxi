Web 前端长度单位

CSS 的长度单位分为两大类：绝对单位（px、pt、cm 等）大小固定；相对单位（%、em、rem、vw、vh 等）需要参照物，会随父元素、根字号或视口变化，是响应式布局的基础。

一、px 绝对单位

100px
200px
300px

1px 是屏幕上固定的小方块，不随窗口大小改变，是最常用的单位。

二、% 相对父元素

width: 25%
width: 50%
width: 75%

百分比相对的是父元素的宽度，父元素变宽时子元素跟着变宽，常用于流式布局。

三、em 相对当前字号

第 1 层：font-size: 1.5em → 24px；width: 8em → 192px
第 2 层：font-size: 1.5em → 36px；width: 8em → 288px

em 相对当前元素自己的 font-size 计算，层层嵌套会一层层放大。

四、rem 相对根字号

第 1 层：font-size: 1.5rem → 24px；width: 10rem → 160px
第 2 层：font-size: 1.5rem → 24px；width: 10rem → 160px

rem 相对根元素 html 的 font-size（浏览器默认 16px），无论嵌套多少层结果都不变。

五、vw / vh 相对视口

25vw
50vw
width: 100%；height: 20vh（窗口越高它越高）

1vw = 视口宽度的 1%，1vh = 视口高度的 1%，拖动浏览器窗口即可看到条形变化。

  • 绝对单位：px、pt、cm、mm、in、pc —— 大小固定，适合打印场景和精确控件
  • 相对单位：%、em、rem、vw、vh、vmin、vmax、ch、ex —— 各有一个参照物
  • 参照物区别：% 参照父元素宽度；em 参照自身字号（会嵌套放大）；rem 只参照根字号
  • 使用习惯：写字号多用 rem（可整体缩放），写组件内部间距多用 em 或 px，满屏与响应式多用 vw / vh
