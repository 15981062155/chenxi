CSS 变量展示 · 陈曦

本页面演示 CSS 自定义属性（变量）：在 :root 中统一定义颜色、间距、圆角与字体， 通过 var() 引用，并借助变量一键切换主题。作者：陈曦。

1. 颜色变量

所有颜色集中定义，改一处即可全局生效，引用时写作 var(--chenxi-primary)。

2. 间距与圆角变量

--chenxi-gap 与 --chenxi-radius 控制卡片间距和圆角，保持页面风格统一。

3. 主题切换

给 <html> 加上 data-theme="dark" 后重写同名变量，整页配色随之改变。

4. 变量回退值

变量未定义时使用第二个参数作为回退：var(--chenxi-not-defined, #e05555)

这段文字使用了回退颜色。

5. 响应式字号

标题字号 --chenxi-title-size 使用 clamp()，随窗口缩放而不失协调。

6. 局部覆盖

变量可在任意元素上重新赋值，子元素自动使用新值，无需覆盖整套样式。
