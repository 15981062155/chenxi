① setTimeout — 延迟执行一次

在指定毫秒后执行一次函数。像"3 秒后弹出提示"。

setTimeout(function() { // 这里的代码只会执行一次 }, 3000);
点击"3 秒后启动"试试

② setInterval — 循环执行

每隔指定毫秒重复执行。像计时器、轮播图、倒计时。

var timer = setInterval(function() { // 每隔 500ms 执行一次 }, 500); // 停止它 clearInterval(timer);
计数：0
