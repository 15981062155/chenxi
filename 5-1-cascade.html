层叠与继承

CSS 的层叠规则：当多个样式规则作用到同一个元素时，浏览器会根据 选择器优先级 进行判断；继承则是父元素样式传递给子元素。

121 陈曦

这段文字同时命中元素选择器、类选择器和 ID 选择器。

最终生效的是 ID 选择器的样式，因为它优先级更高。

父元素设置了 color: #2563eb 和 font-size: 24px，
子元素继承了父元素的基础样式，但如果子元素自己写了样式，则会覆盖继承结果。
  • 优先级规律： ID 选择器 > 类选择器 > 标签选择器
  • 层叠规律： 后写的样式会覆盖前写的样式，前提是优先级相同
  • 继承规律： 某些属性如 color、font-size、font-family 会沿着元素树往下传递
