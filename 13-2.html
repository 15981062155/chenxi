Lucide SVG 图标

Lucide 是一套纯 SVG 图标库：每一枚图标就是一个 <svg> 元素， 内部由 <path>、<circle> 等矢量图形组成，没有字体文件。 它可以由 JS 自动把占位标签替换成内联 SVG，也可以完全手写内联、不依赖任何脚本。 本页使用的 lucide.min.js 已下载到本地 ./cdn/lucide/。

一、两种使用方式

方式 A：JS 自动替换（推荐）

<!-- 1. 引入本地图标库 -->
<script src="./cdn/lucide/lucide.min.js"></script>

<!-- 2. 写占位标签 -->
<i data-lucide="house"></i>

<!-- 3. 页面加载后把占位标签换成内联 SVG -->
<script>
  lucide.createIcons();
</script>

createIcons() 会扫描页面上所有 [data-lucide] 元素， 用对应图标的 SVG 节点把它们整个替换掉，最终 DOM 里留下的是真正的 <svg>。

方式 B：手写内联 SVG（零依赖）

<svg xmlns="http://www.w3.org/2000/svg"
     width="24" height="24"
     viewBox="0 0 24 24"
     fill="none"
     stroke="currentColor"
     stroke-width="2"
     stroke-linecap="round"
     stroke-linejoin="round">
  <path d="M19 14c1.49-1.46 3-3.21 3-5.5A5.5 5.5 0 0 0
    16.5 3c-1.76 0-3 .5-4.5 2-1.5-1.5-2.74-2-4.5-2A5.5 5.5 0 0 0
    2 8.5c0 2.3 1.5 4.05 3 5.5l7 7Z" />
</svg>

复制图标站给出的代码直接粘贴进 HTML 即可，不需要 JS、不需要额外请求， 适合少量图标或对性能极致敏感的场景。

四、尺寸、线宽与颜色

尺寸：改 width / height

16px 24px 40px 64px

内部坐标永远是 24×24，靠 viewBox 做缩放，所以放大不会失真。 也可以像本页这样统一用 CSS svg.lucide { width: 1.3em; } 覆盖尺寸。

线宽：改 stroke-width

1 1.5 2 2.75

这是 SVG 图标相对字体图标最大的优势：线宽可以任意调节， 字体图标做不到（除非买了 Pro 版）。

颜色：stroke="currentColor"

currentColor 表示「跟随当前文字颜色」，所以只要改外层元素的 color， 图标就跟着变；SVG 图标同样可以填充渐变，这是字体图标做不到的。

性能与体积

Lucide 全部图标打包进一个 JS 文件（约 340 KB），按需引入时也可以只打包用到的几枚；相比字体图标，SVG 可被浏览器缓存、也更容易做 tree-shaking。

可访问性

SVG 节点可以加 role="img"、aria-label 等无障碍属性，也可以像本页一样直接用 title 元素提供说明，比字体图标更容易做对。

可改造性

线宽、端点样式、填充、渐变、动画都能自由调整，同一枚图标可以衍生出多种风格，适合做品牌化设计系统。

无障碍与降级

手写内联 SVG 时若 JS 失效，图标依然正常显示；用 JS 替换时建议配合 aria-hidden="true" 标注纯装饰图标。

七、原理：一枚 SVG 图标的结构

<svg
  xmlns="http://www.w3.org/2000/svg"  ← SVG 命名空间
  width="24" height="24"       ← 显示尺寸
  viewBox="0 0 24 24"            ← 内部坐标系 24×24
  fill="none"                 ← 默认不填充
  stroke="currentColor"       ← 描边跟随文字色
  stroke-width="2"            ← 线宽
  stroke-linecap="round"      ← 端点圆润
  stroke-linejoin="round"     ← 拐角圆润
  class="lucide lucide-house"
>
  <path d="M3 10a2 2 0 0 1 .709-1.528l7-5.999…" />
</svg>

三个关键点

  1. viewBox：图形都在 24×24 的坐标系里绘制，显示尺寸再大也只是缩放，不会模糊。
  2. stroke 而非 fill：Lucide 是「描边派」，图标本质是一圈线条，所以线宽可以自由调。
  3. currentColor：颜色交给 CSS 的 color 属性，和文字排版保持一致。

createIcons() 做的事，说白了就是「查表 + 造节点 + 替换节点」： 把 data-lucide="house" 翻译成图标名 House， 从 lucide.icons 里取出路径数据，组装成 <svg> 后替换原来的 <i>。

八、SVG 图标 vs 字体图标

维度 Lucide（SVG） Font Awesome（字体）
本质 矢量路径，随 DOM 存在 字体里的一个字符（Glyph）
线宽 / 风格 可自由调节 stroke-width、端点、填充 只有字体里做好的几种固定风格
颜色 currentColor，还能用渐变 color，单色
尺寸 用 width/height 或 CSS 精确控制 跟随 font-size，倍数类较粗糙
首屏渲染 依赖 JS 替换时略慢；手写内联则立即显示 需等字体文件下载，可能出现闪动
无障碍 可加 role、aria-label、title 需要额外处理，读屏可能读出乱码
适用场景 设计系统、需要精细控制的界面 快速配图、图标数量巨大且风格固定

想看字体图标方案？请看 13-1.html · Font Awesome 字体图标。
