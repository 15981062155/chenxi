🗄️ 数据库 ER 图

智能客服核心实体关系：用户会话 · 知识库条目 · 人工坐席 · 反馈评价

erDiagram
    USER ||--o{ SESSION : initiates
    SESSION ||--|{ MESSAGE : contains
    SESSION }o--|| AGENT : transfers_to
    AGENT ||--o{ SESSION : handles
    MESSAGE }o--|| KNOWLEDGE_MATCH : references
    KNOWLEDGE_BASE ||--o{ KNOWLEDGE_MATCH : matches
    KNOWLEDGE_BASE ||--o{ FEEDBACK : receives
    SESSION ||--o| FEEDBACK : has

    USER {
        bigint user_id PK
        varchar phone
        varchar email
        tinyint vip_level
        datetime created_at
    }
    SESSION {
        bigint session_id PK
        bigint user_id FK
        bigint agent_id FK
        tinyint channel
        tinyint intent
        tinyint status
        datetime start_time
        datetime end_time
    }
    MESSAGE {
        bigint msg_id PK
        bigint session_id FK
        tinyint role
        text content
        float confidence
        datetime created_at
    }
    AGENT {
        bigint agent_id PK
        varchar name
        tinyint dept
        tinyint online
        int total_handle
        int rating_score
    }
    KNOWLEDGE_BASE {
        bigint kb_id PK
        varchar category
        text question
        text answer
        int hit_count
        datetime updated_at
    }
    KNOWLEDGE_MATCH {
        bigint match_id PK
        bigint msg_id FK
        bigint kb_id FK
        float similarity
    }
    FEEDBACK {
        bigint feedback_id PK
        bigint session_id FK
        bigint kb_id FK
        tinyint rating
        text comment
        datetime created_at
    }
