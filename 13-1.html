Font Awesome 字体图标

Font Awesome 是最经典的图标库之一，它的本质是字体图标（Icon Font）： 把整张图标表打包成一个 .woff2 / .ttf 字体文件，再用 CSS 把每个图标映射到字体里的一个 Unicode 字符。 本页所有资源均已下载到本地 ./cdn/font-awesome/，离线也能正常显示。

一、基本用法

<!-- 引入本地样式表 -->
<link rel="stylesheet"
      href="./cdn/font-awesome/css/all.min.css">

<!-- 使用图标：样式类 + 图标名 -->
<i class="fa-solid fa-house"></i>

类名规则：fa-风格 + fa-图标名。常用风格有 fa-solid（实心）、fa-regular（线框/空心）、 fa-brands（品牌标志）。图标名可以在下一节的网格里搜索复制。

三种风格其实是三个独立的字体文件：fa-solid-900.woff2（字重 900）、 fa-regular-400.woff2（字重 400）、fa-brands-400.woff2。 CSS 通过 font-family + font-weight 把它们区分开。

尺寸类只是把 font-size 放大若干倍。因为图标本身是文字， 所以它天然继承父元素的字号与颜色——这是字体图标最方便的地方。

六、原理：字体图标是怎样画出来的

/* ① @font-face 把字体文件注册成 Web Font */
@font-face {
  font-family: "Font Awesome 6 Free";
  font-weight: 900;
  src: url(../webfonts/fa-solid-900.woff2) format("woff2");
}

/* ② 设定字体与字重 */
.fa-solid {
  font-family: "Font Awesome 6 Free";
  font-weight: 900;
}

/* ③ 每枚图标 = 一个 Unicode 码位 */
.fa-house:before  { content: "\f015"; }
.fa-heart:before  { content: "\f004"; }
.fa-star:before   { content: "\f005"; }
.fa-user:before   { content: "\f007"; }

三步看懂一个字体图标

  1. 字形：设计师把图标画成矢量轮廓，转成字体里的一个「字」，比如 \f015 对应房子。
  2. 注入：::before 伪元素把这个字符插到元素内容里，于是页面上就出现了图标。
  3. 排版：既然是文字，它就受 font-size、color、line-height 控制，和文字排版完全一致。

真正的图标长这样： —— 它们只是「长得像图形的字」。

另一个细节：unicode-range 让字体只声明自己能渲染的那一段码位， 没覆盖到的字符会自动回退到系统字体，不会出现「豆腐块」。

七、字体图标的优点与局限

维度 优点 局限
颜色 直接用 color 控制，还能做渐变、继承、悬停变色 只能单色，无法双色/多色（Pro 版双色调另收费）
尺寸 与文字一起缩放，任意分辨率都清晰（矢量字形） 尺寸完全跟随字号，想单独控制要额外包一层
加载 一个字体文件打包上千枚图标，请求数少 字体体积大（fa-solid-900.woff2 约 100 KB），且要等字体下载完才显示
可访问性 可加 aria-hidden、role="img" 等属性 纯装饰时若不处理，读屏软件会读出无意义的字符
形态 实心风格厚重有力，视觉识别度高 只能有字体里预先做好的几种风格，不能自由改线宽

想对比纯 SVG 方案（Lucide）？请看 13-2.html · Lucide SVG 图标。

八、本地资源清单

cdn/
├─ font-awesome/
│  ├─ css/
│  │  └─ all.min.css            ← 页面通过 <link> 引入
│  └─ webfonts/
│     ├─ fa-solid-900.woff2     ← 实心图标（字重 900）
│     ├─ fa-solid-900.ttf       ← 旧浏览器兜底
│     ├─ fa-regular-400.woff2   ← 空心图标（字重 400）
│     ├─ fa-regular-400.ttf
│     ├─ fa-brands-400.woff2    ← 品牌图标
│     ├─ fa-brands-400.ttf
│     ├─ fa-v4compatibility.woff2 ← 兼容 FA4 旧类名
│     └─ fa-v4compatibility.ttf
└─ lucide/
   ├─ lucide.min.js             ← 13-2.html 使用的 SVG 图标库
   └─ lucide.min.js.map

字体图标的路径写在 CSS 的 url(../webfonts/...) 里， 因此 all.min.css 必须和 webfonts/ 保持“一层目录”的相对关系； 把整个 font-awesome/ 目录一起移动，页面依然正常工作。
